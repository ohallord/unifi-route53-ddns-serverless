# Security Policy

## Supported Versions

Only the latest commit on `main` gets security fixes.

## Reporting a Vulnerability

Please **do not open a public issue** for security problems.

Report them privately through GitHub's [private vulnerability reporting](https://github.com/ohallord/unifi-route53-ddns-serverless/security/advisories/new). Include:

* a description of the issue and its impact
* steps to reproduce or a proof of concept
* the affected commit or version

You should get a response within 7 days. Once a fix is released, you'll be credited in the advisory unless you ask not to be.

## Scope

This project deploys into **your** AWS account. Your account configuration, how you store your gateway's credentials, and the security of UniFi or inadyn are out of scope.
